## 一、连接结论

**已完全连通。**

电脑侧原本没有任何 adb 客户端，已通过 `winget` 安装官方
**Google platform-tools 37.0.1**（adb 1.0.41）。

握手过程：

1. Windows 识别为 MediaTek 复合设备 `VID_0E8D&PID_201D`
2. 其中 MI_01 接口签名 `USB\Class_ff&SubClass_42&Prot_01`
   —— **这是安卓 ADB 接口的标准指纹**，由系统 WinUSB 驱动正常加载，
   说明设备侧 USB 调试已正确开启
3. 首次 `adb devices` 返回 `unauthorized`，设备端确认授权后变为 `device`

> ⚠️ `ro.serialno = 0123456789ABCDEF` 是 MTK 默认占位值，**不唯一**，
> 不能作为设备唯一标识使用。

### 平台线索（推断）

基带项目串：

```
gsm.project.baseband = LOKYEE82_WET_KK_GPRS_HW(DEFAULT)
```

其中 **`LOKYEE82` ≈ `joya82`**，`WET_KK` 的 `KK` 指 KitKat。
公开 ROM 库中可检索到同平台固件：

```
MT6582__alps__K0708__4.4.2__K0708_V1.1.0_190802__KOT49H__joya82_wet_kk.zip
```

**推断**：本机与那批 `K0708` 平板同属 **`joya82` 硬件平台**。
ODM 沿用了该平台设计，把系统从 4.4 升到 5.1，
但**基带仍是 KitKat 时代的老固件**（所以串里还写着 `KK`）。
这是这类公版方案非常典型的做法。

**ODM 厂商已确定**：

```
ro.mediatek.project.path    = device/keytak/b906
ro.mediatek.version.release = ALPS.L0.MP2.V1_KEYTAK6582.WT.L
```

**`KEYTAK`** 就是这套固件的 ODM 厂商代号（`KEYTAK6582` = KEYTAK 家的 MT6582 方案）。
`ALPS.L0.MP2.V1` 是 MTK 的 ALPS 基线版本号。这比基带串的推断更硬——
它是**编译期写死的项目路径**，可以直接拿去检索同厂商的其他固件。

**进一步推断**：这是一台**白色/贴牌平板**，非主流品牌行货。
所有厂商定制包的安装时间戳集中在 `2023-06-19 15:30 ~ 15:50` 这 20 分钟内，
是典型的**产线统一烧录**痕迹。

### ⚠️ 两个异常读数

**1. 4 核只开了 1 核**

硬件报告 4 核（`present = 0-3`），但实际只有 cpu0 在线，其余 3 核被 hotplug 关闭，
频率停在最低档 598 MHz。

MTK 的 hotplug 在空闲时确实会关核，但通常会保留 2 核。这里只剩 1 核且低频，
**可能是 ODM 为省电/控温做的激进配置**，也可能是热插拔逻辑有问题。
→ 需要在真机上跑负载复测才能定性。

**2. `/proc/loadavg` 读数不可信**

连续 3 次采样值**完全相同**（7.11 / 7.15 / 7.19），
而 `top` 显示所有进程 CPU 占用均为 0%、内存空闲 1.5 GB。

两者矛盾 → 这是旧 MTK 内核在 tickless idle + hotplug 下的**计数异常**，
不是真有 7 个进程在跑。
→ **不要用 `loadavg` 判断这台机器的负载**，用 `top` 或实际响应速度。

## 五、能力边界

### ✅ 不需要 root 就能做

- **装应用**：`adb install`（限 API 21 + `armeabi-v7a`）
- **启动 / 强停应用**：`am start` / `am force-stop`
- **模拟输入**：`input tap / swipe / text / keyevent` → 可做自动化
- **改系统设置**：`settings put`
- **截图 / 录屏**：`screencap` / `screenrecord`
- **文件互传**：`adb push / pull`
- **看日志**：`logcat`
- **拉起 MTK 工程模式**：`am start` 调 `com.mediatek.engineermode`
- **停用预装应用**：`pm disable-user --user 0 <包名>`
- **设为 Device Owner**：`dpm set-device-owner`（→ Kiosk 锁定）
- **设为默认桌面**：声明 `HOME` category

### ❌ 无 root 做不了

- 修改 `/system`、真正删除预装应用
- 读取其他应用的私有数据（`/data/data/*`）
- 改 `build.prop`、禁用系统组件
- 完整系统备份
- 开无线 ADB（5.1 不支持，且需 root 改 `persist.adb.tcp.port`）

### ⚠️ 现实限制

- **WebView 37**：现代网页基本打不开
- **无中文输入法**
- **Android 5.1 无安全更新**：**不要登录敏感账号**
- 1 核 @ 598 MHz：实际性能远低于 MT6582 理论值

## 六、结论与后续

**定位**：一台 MT6582 平台的**白色/贴牌平板**，跑近原生 AOSP 5.1，
无 root、无第三方应用、无 Google 服务。产线烧录于 2023 年 6 月。

**用途**：作为**定制的单机应用载体**（APK 开机自启 / Kiosk 终端）。
可行性已确认：安装、自启、桌面接管、Device Owner 锁定四条路都通。

**后续待办**：

1. 确认「4 核只开 1 核」是配置问题还是故障（跑负载复测）
2. 实测 `pm disable-user com.android.launcher3` 是否可用来替换桌面
3. 实测 Device Owner 设置后 LockTask 的实际锁定效果
4. 实机 `adb reboot` 验证开机自启
